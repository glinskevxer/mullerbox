# mullerbox

Green sand control for a grey iron jobbing foundry. Sieve analysis and grain
fineness, the AFS property tests the sand lab runs, calibration windows on the
instruments those tests run on, spec bands resolved against the pattern class on
the line, the muller additions that follow from a shift's numbers, and the
attribution that decides whether a scrapped casting is the sand's fault.

Early days. The package installs and the exception hierarchy is settled.
